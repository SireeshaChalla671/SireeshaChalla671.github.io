ChatSphere

Full-stack real-time communication platform

  • Messaging with groups, typing indicators, presence, read receipts, reactions, replies, search, media sharing and voice and video calls.
  • Secure sign-in with email or phone OTP, JWT access and refresh tokens with rotation and revocation, plus rate limiting.
  • Reliable delivery: client-generated message IDs with database uniqueness constraints prevent duplicates on retries.
  • Transactional message saving and cursor-based pagination for large histories; Redis socket sets keep multi-device presence accurate.
  • LiveKit (WebRTC, SFU) for calls with screen sharing and active speaker detection. Includes Web Push, PWA support, tests, Docker Compose and GitHub Actions CI.

Enterprise-Grade Agentic RAG

Grounded question answering over a domain knowledge base

  • A LangGraph agent plans and routes each query, so retrieval runs only when the question needs it.
  • Full pipeline: ingestion, chunking, embeddings, Qdrant vector search, FlashRank reranking and grounded answer generation.
  • NeMo Guardrails and prompt design reduce hallucinations and handle prompt injection, irrelevant retrieval and unsafe requests.
  • FastAPI backend with an LLM abstraction layer for model routing and observability; modular stages make each part easy to test.
